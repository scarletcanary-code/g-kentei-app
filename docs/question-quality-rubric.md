## 良問の定義

以下の 8 項目をすべて満たす問題を「良問」とする。

1. **問題文が一読で意図を理解できる**（曖昧な日本語表現がない）
   - 主語・述語が明確で、何を問うているかが最初の文で判断できる
   - 「〜について正しいものを選べ」「〜として適切なものはどれか」など、問い方が明示されている
   - 二重否定・長すぎる修飾節・省略された主語による誤読を招かない

2. **G検定シラバスの学習目標に直接対応する**
   - `syllabusArea` / `syllabusTopic` フィールドで章・節レベルまでマッピングされている
   - JDLA 公式シラバス（NotebookLM ソース: `f82a549c-19b8-4815-b53a-047df3502595`）に記載の重要概念が問われている
   - 試験範囲外の過度に専門的・最新すぎるトピックを扱わない

3. **正答は学習目標の理解を確認できる内容**
   - 正答を選ぶためには定義の暗記だけでなく、概念の理解・適用が求められる
   - 問題文から正答が自明に推測できるような構造になっていない（問題文の後半に答えが含まれていない）

4. **誤答は実際に受験者が誤りやすい概念・数値・用語を使う**
   - 実際の混同パターン（例: 過学習と未学習、L1正則化とL2正則化）に基づいている
   - 「明らかに違う」誤答（完全な作り話・無関係な概念）を含まない
   - `misconceptionTarget` フィールドで代表的な混同ターゲットが記録されている

5. **問題文だけで正答が一意に決まる**
   - 選択肢を読む前から答えが自明にならない
   - 問題文に答えへのヒントが含まれていない（例: 「〜という手法は〜を行うが、正しいのはどれか」で選択肢に〜と同じ語句が使われている）

6. **解説が正答の根拠と誤答の理由を両方説明している**
   - 正答の根拠（「なぜ A が正しいか」）を 1〜2 文で明示
   - 主要な誤答の「なぜ間違いか」を少なくとも 1 つ説明
   - `optionRationales` フィールドで各選択肢の根拠が補足されている

7. **`source_ref` に NotebookLM の根拠箇所が記録されている**
   - 5 文字以上の文字列で、参照元を識別できる
   - 「JDLA公式シラバス」「Study-AI テキスト第X章」などの形式が望ましい

8. **認知レベルが `cognitiveLevel` フィールドで明示されている**
   - `recall` / `understand` / `apply` / `compare` のいずれか
   - 問題の難易度・問い方と一致している

## 誤答選択肢の設計ルール

以下の 5 タイプを組み合わせて誤答を設計する。「明らかに違う」誤答は禁止。

### 1. `concept_confusion`（概念混同型）
正答と混同しやすい近接概念を誤答に使う。

例:
- 正答: 「過学習（Overfitting）」→ 誤答: 「未学習（Underfitting）」
- 正答: 「L2正則化（Ridge）」→ 誤答: 「L1正則化（Lasso）」
- 正答: 「教師あり学習」→ 誤答: 「強化学習」

設計ポイント: `misconceptionTarget` に混同対象の概念名を記録する。

### 2. `scope_error`（スコープ誤り型）
正答より広いまたは狭いスコープで記述する誤答。

例:
- 正答: 「畳み込みニューラルネットワーク（CNN）は画像認識に特化した深層学習の一種」
- 誤答（広すぎ）: 「CNNはすべての機械学習タスクに最適なモデルである」
- 誤答（狭すぎ）: 「CNNは2次元グレースケール画像のみを処理できる」

### 3. `causal_error`（因果関係誤り型）
因果関係を逆転または誤って紐づける誤答。

例:
- 正答の因果: 「データ数増加 → 過学習リスク低下」
- 誤答: 「データ数増加 → モデルが複雑になるため過学習が増加する」

### 4. `term_swap`（用語置換型）
同一概念の別名・略語・類義語と入れ替える誤答。

例:
- 正答: 「確率的勾配降下法（SGD）」→ 誤答に「バッチ勾配降下法」
- 正答: 「正規化」→ 誤答に「標準化」（文脈で使い分けが必要な場面で）

### 5. `outdated_or_partial`（古い定義・部分的記述型）
過去の定義または不完全な記述を含む誤答。

例:
- 正答: 「Transformerはself-attentionを中心とした構造を持ち、並列処理が可能」
- 誤答: 「Transformerは再帰型の処理を行い、系列順に計算が進む」（RNNとの混同）

## 問題タイプ比率

`cognitiveLevel` フィールドで管理する認知レベルと、目標比率を定める。

| cognitiveLevel | 定義 | 目標比率 |
|---|---|---|
| `recall` | 定義・用語・事実の想起 | ≤ 30% |
| `understand` | 概念の説明・適用範囲の判断・仕組みの理解 | ≥ 40% |
| `compare` | 2 つ以上の概念の異同・優劣・適用条件の比較 | ≥ 20% |
| `apply` | 具体的なシナリオ・数値・コードへの適用 | ≥ 10% |

**注意**: 0031 時点では既存 292 問の `cognitiveLevel` は未設定。目標比率の達成は 0032 以降のタスクで対応する。

### 認知レベルの判定基準

- **recall**: 「〜とはなにか」「〜の定義として正しいものはどれか」といった定義型の問い。選択肢の暗記で対応できる。
- **understand**: 「〜が〜である理由はどれか」「〜の特徴として正しいものはどれか」。仕組みの理解が必要。
- **compare**: 「〜と〜の違いとして正しいものはどれか」「〜と比較して〜の特徴はどれか」。2 概念以上の比較が必要。
- **apply**: 「〜という状況で適切な手法はどれか」「〜の計算結果として正しいものはどれか」。知識の応用が必要。

## レビュー観点

品質保証は 2 段階で実施する（0031 時点はいずれも人手）。

### Content Reviewer（内容レビュー）

担当: G検定合格者または機械学習の実務経験者

確認項目:
1. 問題文・正答・解説の事実が正確か（NotebookLM の出典と照合）
2. シラバス範囲内のトピックか
3. 誤答がすべて「それらしい誤り」として設計されているか（`concept_confusion` / `scope_error` 等）
4. `source_ref` が適切な参照元を指しているか
5. 解説の長さと質（40 文字以上、正答根拠と誤答理由の双方が含まれるか）

### Learner Reviewer（学習者視点レビュー）

担当: G検定受験を目指している初学者または中級者

確認項目:
1. 問題文を読んで何を問われているかが一読で理解できるか
2. 選択肢を読む前から答えが自明でないか（問題が機能しているか）
3. 難易度 `difficulty` の設定が体感と一致しているか
4. 解説を読んで「なるほど」と理解できるか

### 将来の自動レビュー（0033+ スコープ）

Felo / Claude API による:
- 事実精度の自動判定
- 問題文の日本語品質チェック
- G検定シラバス適合度スコアリング

## サンプル良問・悪問

### 良問サンプル 1

```
問題: 「過学習（Overfitting）が発生する主な原因として最も適切なものはどれか。」
選択肢:
  A. 訓練データに対してモデルが過度に適合し、汎化性能が低下すること（正答）
  B. モデルの表現力が不足しており、訓練データに対する誤差も大きいこと
  C. 学習率が低すぎて、勾配降下が収束しないこと
  D. データの正規化が行われていないため、特徴量の分布が偏ること
```

良い理由:
- 選択肢 B は「未学習（Underfitting）」を指す `concept_confusion` 型の誤答
- 選択肢 C は学習率に関する別の問題（`causal_error` 型）
- 選択肢 D は正規化に関する別の問題（`causal_error` 型）
- 各誤答が「それらしい誤り」として機能し、明らかに違う誤答がない
- `cognitiveLevel: "understand"` が適切（概念の理解を確認）

### 良問サンプル 2

```
問題: 「サポートベクターマシン（SVM）とロジスティック回帰を比較したとき、SVM の特徴として正しいものはどれか。」
選択肢:
  A. マージン最大化により決定境界を求める（正答）
  B. 確率的な出力（クラス帰属確率）を直接計算できる
  C. 出力が 0 から 1 の確率値であるため、閾値調整が不要
  D. ロジスティック回帰より常に精度が高い
```

良い理由:
- `cognitiveLevel: "compare"` が適切（SVM とロジスティック回帰の比較）
- 選択肢 B・C はロジスティック回帰の特徴（`term_swap` / `concept_confusion`）
- 選択肢 D は「常に」という絶対表現で誤答として機能（ただし V21 WARN 対象）

### 悪問サンプル 1（文字数バイアス型 / V7 FAIL 相当）

```
問題: 「深層学習の活性化関数として正しいものはどれか。」
選択肢:
  A. ReLU（正答）
  B. ロジスティック回帰は活性化関数の一種であり、深層学習に広く使われる手法である
  C. SVM
  D. k近傍法（k-NN）
```

悪い理由:
- 選択肢 B だけが極端に長く（V7: 文字数比 > 1.6）、受験者に文字数バイアスを与える
- 選択肢 C・D は単語レベルで短すぎる
- 選択肢間の長さが統一されていない

修正方針: すべての選択肢を同程度の文字数（±1.6 倍以内）に揃える

### 悪問サンプル 2（定義型過剰 / V20 WARN 相当）

```
問題: 「バックプロパゲーションとは何か。」
選択肢:
  A. 誤差逆伝播によってモデルのパラメータを更新する手法（正答）
  B. 順方向に活性化値を計算していく処理
  C. データを正規化して学習を安定させる前処理
  D. ランダムにニューロンを無効化することで過学習を防ぐ手法
```

悪い理由:
- 「〜とは何か」という定義型（`recall` レベル）の問いが全体の 30% を超えると単調になる
- この形式だけでは G 検定の理解・適用レベルの問いに対応できない
- 解説が正答の説明だけで、誤答の「なぜ間違いか」が説明されていない

修正方針: `cognitiveLevel: "understand"` 相当の問い方に変換する（例: 「バックプロパゲーションが深層学習の学習において果たす役割として正しいものはどれか」）
